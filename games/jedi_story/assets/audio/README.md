# Custom sounds and music

Drop your own audio files here, then set their paths in `js/audio-config.js`. For example:

```js
level1: "assets/audio/temple-theme.mp3",
```

Anything left as `null` keeps its generated version. The full instructions and list of names are in [Add your own sounds and music](../../README.md#add-your-own-sounds-and-music).
